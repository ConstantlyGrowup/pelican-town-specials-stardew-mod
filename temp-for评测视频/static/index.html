    REFERENCE ANSWERS

    题目的参考答案怎么确定

    参考“合理”的题：项目里已经确认过的现实原料和游戏原料对应关系。

    参考“不合理”的题：明显属于不同类别的原料对应，例如把姜对应成鱼。这组题专门用来检查 JEV 会不会接受明显错误的对应。

    没有收录不等于错误：项目尚未确认某种对应时，不会因此直接判它错误。

    游戏译名：Wheat Flour 在游戏原版中是小麦粉；游戏中文显示“大麦粉”，评测仍按小麦粉理解。

    怎么算对：JEV 的选择要和参考答案一致。无法判断、请求失败或未完成的题，也会计入全部题目数。
